# MSPM0G3507 LaunchPad + MG996R 舵机台架测试

## 接线

- PA12（LaunchPad J4.8，TIMG0-C0）→ MG996R 信号线（黄/橙）
- 独立 5~6 V 电源正极 → MG996R 红线
- 独立电源 GND → MG996R 棕/黑线
- TI LaunchPad GND → 独立电源 GND

不要从 LaunchPad 的 3.3 V 给舵机供电。MG996R 堵转电流可能达到约 2.5 A，建议使用峰值至少 3 A 的 BEC，并在舵机电源旁增加 470~1000 uF 电容。

## 烧录和测试

1. 先断开舵机电源，只连接 LaunchPad 和 XDS110。
2. 将本目录作为 CCS 工程导入并 Build。
3. 连接 PA12 信号线和共地，再接通独立 5~6 V 舵机电源。
4. Flash/Debug 后运行。程序上电先保持约 1500 us 中位 1 秒。
5. 在 CCS Watch 中观察并修改 `g_servo_pulse_ticks`：
   - 188：约 1500 us，中位
   - 125：约 1000 us，一侧
   - 250：约 2000 us，另一侧
6. 首轮不要超过 100~275 ticks；出现持续嗡鸣、撞限位或明显发热时立即断舵机电源。

`g_pwm_updates` 和 `g_test_seconds` 用于确认程序仍在运行。板载灯约每 500 ms 翻转一次。

## 记录项目

- 中位脉宽和机械位置
- 两侧安全极限脉宽
- 空载单程时间
- 接上合页、水管和钢球后的单程时间
- 是否抖动、卡滞、回差明显
- 电源电压是否掉落、舵机是否发热

## 2026-07-29 空载验证结论

- 主控：MSPM0G3507 LaunchPad，USB 供电。
- 舵机：Tower Pro MG996R，7.4 V 电池经降压模块输出 5 V 独立供电；舵机地与 LaunchPad 地共地。
- PWM：PA12 / TIMG0-C0，50 Hz；`g_servo_pulse_ticks` 的 100~275 已实测可灵活转动。
- 从操作者测试视角看，数值增大时逆时针转动，数值减小时顺时针转动。
- 供电、回中、正反向动作和稳定性主观检查正常，没有观察到明显抖动或异常复位。
- 100→275 的大范围空载动作约为 0.4~0.6 s，暂记约 0.5 s；该数据来自手机视频 0.1 s 级时间轴，后续负载测试再精测。
- 当前结论：MG996R 空载验证通过，暂不采购替代电机。待合页、连杆和 25 cm PPR 摆杆完成后继续做负载、回差、温升和供电压降测试。
- AS5600 磁编码器已购买，预计到货后用于合页转轴角度反馈与 PWM—角度标定。
