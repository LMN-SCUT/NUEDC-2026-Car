# K230 视觉模块

K230 只负责图像采集、目标识别和观测结果输出，不直接执行底盘或舵机控制。

## 已迁移的历史代码

历史代码暂存于 `legacy/previous-project/`，尚未认定为正式比赛版本：

| 内容 | 当前判断 | 后续动作 |
|---|---|---|
| `k230/main_candidate.py` | 特定赛题留档 | 只保留一份完整旧算法，用于回看程序组织方式，不作为新题基础 |
| `k230/uart_smoke_node.py` | 通信价值较高 | 不接视觉时单独验证 K230 串口；协议定稿后改用新帧格式 |
| `k230/prototypes/find_rects.py` | 通用案例 | 参考矩形检测 API 与图像处理流程 |
| `k230/prototypes/sensor_demo.py` | 通用案例 | 参考摄像头初始化、采集与资源释放 |
| `k230/prototypes/display_demo.py` | 通用案例 | 参考虚拟屏、LCD、HDMI 与 IDE 显示初始化 |

## 使用边界

- `legacy/` 中的代码保留原始逻辑，可能含旧 F407 和旧引脚假设。
- 未完成 K230 实机测试前，不把任何历史脚本称为稳定版本。
- 新代码应放在后续建立的正式运行目录中，不继续堆进 `legacy/`。
- 原目录中的重复特定赛题算法未迁入仓库；完整原件仍保留在 `D:\坤坤杯\VISION\k230`。

## 第一轮验收

1. K230 能稳定启动摄像头并持续运行 10 分钟。
2. 能在 IDE 画面中显示检测结果和帧率。
3. 未接主控时，串口脚本能按固定频率发送测试帧。
4. 接主控后，连续收发无卡死、无明显丢帧，失锁时输出安全状态。

## 新协议冒烟测试

将以下两个文件放到 K230 的同一目录：

- `examples/uart_protocol_smoke.py`
- `../shared/protocol/python/vision_link.py`

运行 `uart_protocol_smoke.py` 后会以 30 Hz 发送模拟视觉观测、以 2 Hz 发送心跳，并接收主控的模式、启停和参考点命令。当前沿用历史配置 `UART3、TX=32、RX=33`，上板前必须根据实际 K230 型号核对引脚复用。
