# K230 Wi-Fi RTSP 图传验证

## 2026-07-29 验证结论

- K230 以 STA 模式连接手机 2.4 GHz 热点，Windows 电脑与 K230 位于同一局域网。
- 电脑可 Ping 通 K230，RTSP TCP 端口 8554 可连接。
- VLC 能通过 K230 打印的 `rtsp://<ip>:8554/video` 地址显示画面。
- 纯推流测试配置为 512x288、H.264、2000 kbps、15 fps；VLC 使用最低延迟策略和约 233 ms 网络缓存后，显示延迟明显降低。
- 摄像头固定、仅前景目标运动时显示稳定；摄像头大幅晃动时可能花屏。原因是画面整体变化增加了瞬时码率，同时低缓存降低了抗网络抖动能力。
- 当前结论：K230 自带 Wi-Fi 可作为图传基线，暂不采购独立图传。最终决定需等待装车后完成振动、连续录像和赛场干扰测试。

## 使用

1. 将 `rtsp_no_ai_wifi_test.py` 复制到 K230/CanMV 工作目录。
2. 仅在本地填写 `YOUR_SSID` 和 `YOUR_PASSWORD`，不要提交真实密码。
3. 运行后以串口打印的 RTSP URL 为准；手机热点重新连接或断电后 IP 可能改变。
4. VLC 打开该网络串流。正式展示建议适当增加缓存，以完整清晰录像优先；闭环控制必须在 K230 本地完成，不依赖电脑端画面。
