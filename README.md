# NUEDC 2026 Car

全国大学生电子设计竞赛控制类小车项目代码仓库。

## 模块

- `vision-k230/`：K230 视觉采集、识别与观测结果输出。
- `controller-stm32/`：STM32 候选主控的驱动与控制代码。
  - `controller-stm32/h60-f407-line-car/`：OpenCTR H60 / STM32F407VET6
    标准外设库小车工程，包含四路电机、参考成功工程移植的 I2C 八路灰度、
    HC-05、K键启动和H题环形地图循迹。当前版本不使用编码器PI和堵转状态机。
- `controller-ti/`：LP-MSPM0G3507 候选主控的驱动与控制代码。
- `shared/protocol/`：K230 与最终主控共享的通信协议、字段定义和测试帧。
- `tests/`：串口、协议和联调测试。
- `docs/`：编译、烧录、运行和验收说明。

## 协作规则

1. `main` 只保留经过验证的稳定版本，不直接在 `main` 上开发。
2. 每项工作从 `main` 创建短期分支，例如 `feature/k230-detection`、`feature/ti-uart`。
3. 完成功能和基本测试后发起 Pull Request，由至少一名队友查看后合并。
4. 一次提交只处理一类改动；提交信息说明改动内容和验证硬件。
5. SDK、安装程序、编译输出、密钥和大型资料不进入仓库。
