# H60 循迹车元件与引脚说明

本文只说明车辆使用的元件、作用和引脚连接，方便后续接线与阅读代码。

## 1. 主控制器

- 开发板：OpenCTR H60。
- 主控芯片：STM32F407VET6。
- 作用：读取灰度传感器、控制四个电机、读取按键，并通过 HC-05 输出串口信息。
- 系统主频：168 MHz。

## 2. 感为八路灰度传感器

### 作用

灰度传感器安装在车辆前部下方，用八个红外探头检测地面黑线位置。主控根据黑线位于传感器左侧、中央还是右侧，调整左右轮速度完成循迹。

### 接线

| 灰度传感器 | STM32F407 | 作用 |
|---|---|---|
| SDA | PC2 | 软件 I2C 数据线 |
| SCL | PC3 | 软件 I2C 时钟线 |
| GND | GND | 电源地，必须共地 |
| VCC | 按模块额定电压连接 | 模块供电 |

### 电气注意事项

- PC2、PC3 使用开漏方式。
- SDA、SCL 建议分别通过 4.7 kΩ～10 kΩ 电阻上拉到 3.3 V。
- SDA、SCL 的高电平不能超过 STM32 的允许电压。
- 信号线应尽量短，并远离电机电源线。
- 灰度传感器、主控板和电机驱动必须共地。

### 代码中的传感器顺序

- bit0 对应 S1。
- bit7 对应 S8。
- 原始位为 1 表示白色，0 表示黑色。
- S1～S8 的位置权重为：

```text
-8, -6, -3, -1, +1, +3, +6, +8
```

- 黑线偏向 S1 一侧时误差为负。
- 黑线偏向 S8 一侧时误差为正。

### 通信参数

- I2C 地址：`0x4C`。
- `0xAA`：握手命令，模块应返回 `0x66`。
- `0xDD`：读取八路数字位图。

相关代码：`User/gray.c`、`User/gray.h`。

## 3. HC-05 蓝牙串口模块

### 作用

HC-05 将 STM32 的串口信息无线发送到电脑或手机，用于查看灰度数据、电机输出和程序状态。

### 接线

| HC-05 | STM32F407 | 作用 |
|---|---|---|
| RXD | PB10 / USART3_TX | 接收 STM32 发出的数据 |
| TXD | PB11 / USART3_RX | 向 STM32 发送数据 |
| GND | GND | 电源地，必须共地 |
| VCC | 按所用 HC-05 底板标称电压连接 | 模块供电 |

注意：串口采用交叉连接，即 STM32 的 TX 接 HC-05 的 RXD，STM32 的 RX 接 HC-05 的 TXD。

### 串口参数

```text
波特率：115200
数据位：8
停止位：1
校验位：无
```

相关代码：`User/serial.c`、`User/serial.h`。

## 4. 四路直流编码器电机

### 作用

车辆使用四个直流减速电机。主控通过 H60 板载 AT8236 电机驱动芯片控制每个电机的转速和方向。

### 轮位

| 电机接口 | 车辆上的位置 |
|---|---|
| MA | 右后轮 |
| MB | 左后轮 |
| MC | 右前轮 |
| MD | 左前轮 |

因此：

- 左侧轮组为 MB、MD。
- 右侧轮组为 MA、MC。

### PWM 引脚

| 电机 | STM32 引脚 | 定时器通道 | 车辆前进时使用的输入 |
|---|---|---|---|
| MA | PE9、PE11 | TIM1 CH1、CH2 | MA2 / PE11 |
| MB | PE13、PE14 | TIM1 CH3、CH4 | MB1 / PE13 |
| MC | PE5、PE6 | TIM9 CH1、CH2 | MC2 / PE6 |
| MD | PB14、PB15 | TIM12 CH1、CH2 | MD1 / PB14 |

### PWM 参数

- PWM 频率：2 kHz。
- PWM 计数周期：999。
- PWM 比较值范围：0～999。
- 比较值 0 表示无 PWM 输出。
- 比较值越大，电机输出占空比越高。

电机命令为 0 时，驱动器的两个控制输入均为低电平，电机处于停止输出/滑行状态，不是主动制动。

相关代码：`User/motor.c`、`User/motor.h`。

## 5. 板载 K 按键

### 作用

K 按键用于启动循迹程序。

| 元件 | STM32 引脚 | 有效电平 |
|---|---|---|
| K 按键 | PE1 | 按下为低电平 |

代码中启用内部上拉，并使用 25 ms 软件消抖。

相关代码：`User/key.c`、`User/key.h`。

## 6. 板载蜂鸣器

### 作用

蜂鸣器用于声音提示。当前程序启动时将其关闭。

| 元件 | STM32 引脚 | 电平作用 |
|---|---|---|
| 蜂鸣器 | PE0 | 低电平关闭 |

相关代码：`User/board.c`。

## 7. 板载 QMI8658A 惯性传感器

### 作用

QMI8658A 可以测量车辆加速度和角速度。

| QMI8658A | STM32F407 | 外设 |
|---|---|---|
| SCL | PB6 | I2C1_SCL |
| SDA | PB7 | I2C1_SDA |

灰度传感器使用 PC2/PC3，QMI8658A 使用 PB6/PB7，两组 I2C 引脚不要混接。

相关代码：`User/imu.c`、`User/imu.h`。

## 8. 引脚汇总

| 引脚 | 连接元件 | 功能 |
|---|---|---|
| PC2 | 灰度传感器 SDA | 软件 I2C 数据 |
| PC3 | 灰度传感器 SCL | 软件 I2C 时钟 |
| PB10 | HC-05 RXD | USART3_TX |
| PB11 | HC-05 TXD | USART3_RX |
| PE9、PE11 | MA | 右后电机 |
| PE13、PE14 | MB | 左后电机 |
| PE5、PE6 | MC | 右前电机 |
| PB14、PB15 | MD | 左前电机 |
| PE1 | K 按键 | 低电平按下 |
| PE0 | 蜂鸣器 | 低电平关闭 |
| PB6、PB7 | QMI8658A | 板载硬件 I2C1 |
